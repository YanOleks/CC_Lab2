# Завдання 2. PoC-інтеграція з відкритим хмарним API Open-Meteo

Проєкт реалізовано в рамках навчального курсу «Хмарні обчислення» (Завдання 2. Семінар-презентація).

У репозиторії представлено демонстраційний PoC-проєкт інтеграції з відкритим хмарним сервісом Open-Meteo API та презентація з описом API і сфер його застосування.

## 1. Опис обраного API

Open-Meteo API — відкрита хмарна платформа чисельного прогнозування погоди.
* Протокол: HTTP GET (RESTful)
* Формат даних: JSON
* Доступ: вільний, без потреби в реєстрації, API-ключах чи банківських картках
* Основні параметри запиту:
  * `latitude`, `longitude` — координати локації
  * `wind_speed_10m`, `wind_gusts_10m` — швидкість та пориви вітру (м/с)
  * `precipitation`, `precipitation_probability` — кількість і ймовірність опадів
  * `soil_moisture_0_to_1cm` — вологість ґрунту

Також використовується Open-Meteo Geocoding API для пошуку координат за назвою міста.

## 2. Що робить PoC (main.py)

Скрипт отримує телеметрію в реальному часі та виконує два прикладні розрахунки:
1. Модель вітрогенератора (2.0 МВт): розрахунок поточної потужності за кубічним законом Беца (P ~ v^3) та спрацьовування аварійного захисту під час штормових поривів (> 25 м/с).
2. Модуль водозбереження: оцінка доцільності ввімкнення поливу на основі вологості ґрунту, швидкості вітру (запобігання розвіюванню крапель) та опадів у найближчі 6 годин.

## 3. Запуск проєкту

### Встановлення залежностей:
```bash
pip install -r requirements.txt
```

### Запуск програми:
```bash
python main.py
```
Програма запропонує ввести назву міста або натиснути Enter для вибору Києва за замовчуванням. Також підтримується передача міста через аргумент:
```bash
python main.py --city "Одеса"
```

## 4. Сфери застосування API

1. Відновлювана енергетика: прогнозування генерації вітрових електростанцій для балансування навантаження в енергомережі та захист турбін від штормів.
2. Агротехнології: автоматизація систем поливу (блокування насосів перед дощем економить воду та електроенергію).
3. Комунальні служби (Smart City): оптимізація міських систем опалення при зміні температури та підготовка зливової каналізації.
4. Логістика: коригування маршрутів транспорту в обхід несприятливих погодних умов.
